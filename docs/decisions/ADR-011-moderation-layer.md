# ADR-011: 内容审核层 = 可插拔 + 可关闭 + 基础词表（回应 OPEN-001 / PRD F6，P0 不降级）

## Status
Accepted (2026-10-09)

## Background
"面向国内用户"存在合规要求，同时产品承诺"单机自部署、创作自由"。PRD 将内容审核层列为 **P0 不降级项**（F6），并要求**可配置、可关闭**；OPEN-001 需架构师给出审核层成本评估与形态裁决。

## Decision
1. **接口可插拔**：定义 `ModerationProvider`（`check_input` / `check_output`），v1 在 LLM 调用**前**与输出回流**后**各拦一次。
2. **v1 默认实现 = `builtin_wordlist`（基础词表 + 正则）**，成本约 1–2 人日；**不做本地分类模型**（避免与 16GB 显存争用、边际收益低）。
3. **单机可整体关闭**（`enabled=false`）：兼顾自部署场景的创作自由，避免硬编码审核劝退创作者。
4. **命中即拦截**：`block_on_match=true` 时返回中性提示 + 错误码 4031，**不产生 LLM 调用**（省成本 + 合规）。
5. **输出标识**：默认附"AI 生成内容"标识。
6. **云适配器保留**：`ModerationProvider: cloud`（云内容安全 API）供上云期启用，接口不变。
7. 配置通过 `GET/PUT /api/v1/config/moderation` 管理。

## Consequences
- 正面：低成本满足合规 + 保留创作自由；上云只换 provider 实现。
- 负面：基础词表拦截率/误拦率需按 PRD §8 指标（≥95% / ≤5%）人工抽检调优；语义级漏判存在（待云适配器补强）。
- 约束：词表策略由运营/合规侧维护；命中日志须可审计但脱敏。
