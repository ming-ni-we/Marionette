## 用户新议题：做成游戏上 Steam 能否规避限制（Phase 1 之后）

**登记为 OPEN-008（waiting-on-external-condition）**

已联网核实的监管事实（2026-10 时点）：
- **版号侧**：Steam 全球区**不需要**中国游戏版号 —— 实务定性为「跨境数字贸易」，中国玩家购买视为个人自用进口（律师专文 + chinagamelegal 实务分析均持此说）；「Steam 中国/蒸汽平台」（Valve+完美世界）**需要**版号。行政处罚无域外效力（只适用于境内行为）。
- **生成式AI侧（真卡点）**：三轨制 —— 算法备案（**并行必办**，2-4 月）/ 大模型登记（纯调已备案 API，1-3 月）/ 大模型备案（自研或深度微调，6-8 月）。
- **关键分界（对本项目最致命）**：若在前端对 API 输出做二次处理（内容过滤、重组、格式优化），可能被认定对模型的「实质性修改」→ 从「登记」升级为「备案」。本平台的世界书注入 / 上下文组装 / 预设模板 / 审核过滤**正好全落在这一条上**。
- **「公众」= 不特定对象**，B2B 也可能算。
- 执法强度：截至 2026-06-30 全国 988 款生成式AI服务完成备案、598 款完成登记；同期「清朗·整治AI应用乱象」专项行动处置违规 AI 产品 **14,000+ 款**；2026-03 无锡案例：调 API 未登记 + 未做安全评估 → 被约谈并责令下线。
- **《人工智能生成合成内容标识办法》**（2025-09-01 施行，配套强制性国标同步实施）：显式标识 + 隐式标识（元数据含 AIGC 字段）；**第 7 条**要求应用分发平台上架审核时核验生成合成标识材料；第 9 条允许用户主动索取无显式标识内容，但需用户协议明确 + 日志留存 ≥6 个月；第 10 条禁止提供删除/篡改标识的工具或服务。
- 内容红线：娱乐范畴（暴力/恐怖/一般成人向）在 Steam 全球区监管容忍度高；**地缘政治 / 国家主权 / 历史虚无主义 = 零容忍**，触发的是技术阻断（ISP 屏蔽）而非法律诉讼。

**项目总监判断**：换平台不改变义务；决定合规量级的是「模型能力由谁提供」。Phase 1 锁定的**单机自部署工具形态恰是合规最干净的形态**（不是妥协，是设计选择）——用户自装、BYOK 或本地模型，平台不提供模型能力、不托管内容、不面向境内公众。建议 v1 形态不变，发行形态作为 v2 商业化单独立项；若变更则属 Spec 变更流程的**大改**（改变核心用户流程/形态）→ 需回 Phase 0。

**腾讯云采购调研（已联网核实）**：

ICP 备案规则（腾讯云官方文档）：
- 域名解析到**境内**服务器 → 必须 ICP 备案，**否则腾讯云会拦截访问并跳到提醒页**
- ⚠️ 关键：官方原文「**不论设置哪个端口都能被监测到**」→ 想用非标端口绕过 80/443 是**无效的**
- 例外：**不用域名、仅用公网 IP 直接访问测试** → 可暂不备案（官方认可）
- **境外服务器（含中国香港）→ 无需备案**（官方明确）

轻量应用服务器价格（2026 采购季，个人专享限 1 个）：
- 2核2G4M / 上海 / 1年 → 99 元（原价 576）
- 2核4G5M / 上海 / 1年 → 188 元（原价 780）
- 4核8G12M / 上海 / 1年 → 880 元（原价 2760）
- 境外 2核4G30M（首尔）→ 1月 28.98 元；1年 199 元
- 轻量远优于 CVM（同配置 CVM 300–600 元/年起）；轻量对新手友好（不用懂 VPC/安全组/弹性 IP）

**给用户的采购建议**：腾讯云**轻量应用服务器** · 2核4G · **境外（中国香港）地域** · Ubuntu 22.04 LTS · 包年
理由：免备案即可用域名 + Caddy 自动 HTTPS；深圳→香港延迟低；价格与境内档接近（约 200 元/年）；避免 1–3 周备案等待。境内节点只有在"不绑域名、只用 IP"时才不用备案，但那样无法签公共证书 → 会话令牌与 API key 走明文，不可接受。
